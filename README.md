# 🎬 Go Video Streamer

[![Go](https://img.shields.io/badge/Go-1.22+-00ADD8?style=flat&logo=go)](https://go.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)
[![Release](https://img.shields.io/github/v/release/sudowhiterose/go-video-streaming?display_name=tag)](https://github.com/sudowhiterose/go-video-streaming/releases)

A minimalist service for video streaming. The backend is powered by Go, metadata is managed in a Docker-hosted PostgreSQL database, and video files are streamed directly from local storage.

---

## ⏱️ Quick Start Guide
```
download latest release 
7z x go-video-streamer-linux.zip //or tar -xvf go-video-streamer-linux.zip
mkdir storage //pull this your videos
chmod +x run.sh
sudo ./run.sh
go to http://localhost:8080

```
